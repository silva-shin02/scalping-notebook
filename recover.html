🛟 データ復元ツール

Chrome が内部に保存しているファイルから、消える前のデータを探して取り出します。このページは何も書き換えません（読むだけ）。
手順
  1. Chrome をすべて閉じる（タスクバーの Chrome も右クリック→ウィンドウを閉じる）。
  2. エクスプローラーのアドレス欄に %LOCALAPPDATA%\Google\Chrome\User Data と入れて開く。
    その中の Default（Chromeのユーザーを分けている場合は Profile 1 など）→ Local Storage → leveldb フォルダを開く。
  3. leveldb フォルダをまるごとデスクトップにコピーする（元のフォルダは触らない）。
  4. Chrome を開くとき、「タブを復元」はしない。スキャルピングノートブックのタブは開かずに、このページだけを開く。
  5. 下の「📁 フォルダを選ぶ」で、デスクトップにコピーした leveldb フォルダを選ぶ。
同期の控え（IndexedDB）も探す
  1. Chrome を閉じた状態で、…\User Data\Default\IndexedDB を開く。
  2. https_silva-shin02.github.io_0.indexeddb.leveldb フォルダと、あれば https_silva-shin02.github.io_0.indexeddb.blob フォルダを、まるごとデスクトップにコピー。
  3. 「📁 フォルダを選ぶ」をもう一度押し、コピーした .leveldb フォルダを選ぶ。.blob フォルダがあれば、もう一度押して .blob フォルダを選ぶ（結果は前の分に追加されます）。
または
「フォルダを選ぶ」で、コピーしたフォルダ（leveldb や .blob）をそのまま選べます。中の奥のフォルダのファイルも全部読みます。ブラウザに「アップロードしますか」と聞かれますが、実際はどこにも送りません（このページの中で読むだけ）。
